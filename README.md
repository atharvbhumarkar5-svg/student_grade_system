# Student Grade Management System (SGS)

A modular, test-driven Python application designed for terminal-based academic evaluation, GPA computation, and cohort analytics.

## Features
- **Data Persistence**: JSON-backed storage layer ensuring data integrity across runs.
- **Academic Grading Engine**: Standard 10-point scale grade mapping and GPA derivation.
- **Analytics & Aggregations**: Instant calculation of cohort averages, toppers, and grade spreads.
- **Input Sanitization**: Zero tolerance for malformed inputs, out-of-bound marks, or ID collisions.
